# Coze 配置包使用说明

## 导入步骤（约 10 分钟）

1. 在扣子新建 Bot，命名「小汇·网点智能接待与导览助手」。
2. 打开 `01_提示词_客户模式.md`，把代码块内文本整段粘贴到「人设与回复逻辑」。
3. 知识库 → 新建知识库 → 上传 `03_知识库_对外分册.txt`（自动分段，分段符 `##`）→ 回到 Bot 挂载该知识库，检索策略用「混合检索」，返回 3 段。
4. 把 `05_意图分流决策表.csv` 的优先级与动作填进「意图识别 / 对话流」的条件分支，顺序照表：应急 > 投诉 > 人工 > 进度 > 理财/贷款/账户 > 其他服务 > 未识别。
5. 按 `06_工作流与插件设计.json` 的 nodes 搭建工作流，插件先用「HTTP 请求」节点占位，接口地址填行内系统（见主 README 的接口替换点）。
6. 柜员版另建一个 Bot（仅内部可见）：提示词用 `02_提示词_柜员模式.md`，知识库同时挂载 `03` 与 `04_知识库_内部政策与SOP_仅柜员.txt`。
7. 发布渠道：客户版发布到公众号/网点大屏/小程序；柜员版仅发布到飞书内部群或企业工作台，并加「工号鉴权」前置节点。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `01_提示词_客户模式.md` | 客户版人设与合规红线，直接粘贴 |
| `02_提示词_柜员模式.md` | 柜员版人设，含引用格式与禁止项 |
| `03_知识库_对外分册.txt` | 22 篇对外文档（产品/业务/网点/投诉） |
| `04_知识库_内部政策与SOP_仅柜员.txt` | 8 篇内部文件，含已废止与即将生效样本，用于验证版本提示 |
| `05_意图分流决策表.csv` | 与流程图一致的分流表，可直接映射为对话流分支 |
| `06_工作流与插件设计.json` | 节点、接口契约、验收用例 |

## 注意

- Coze 目前没有通用「一键导入工作流」格式，`06` 是节点与接口说明，需在可视化编排里手工搭一次。
- `04` 内含内部文件，务必只挂在柜员版 Bot，且发布渠道限制为行内可见。
- 知识库文件里每篇都带「状态」字段，务必让提示词保留该字段输出，避免把已废止口径当现行口径引用。
